# 🎯 SkillSync

> An AI-powered employee skill tracking & assessment platform built with vanilla JavaScript — no frameworks, no dependencies, just pure web tech.

## 🌐 Live Demo
🔗 https://skillsync-orpin.vercel.app/

## 💡 About
SkillSync is a single-file web application that helps organizations track, assess, and improve employee skills using an AI chatbot, dynamic quizzes, and visual analytics — all running entirely in the browser.

## ✨ Features
- 🤖 Mock AI chatbot for personalized skill guidance
- 📝 Dynamic quiz generator for skill assessment
- 📊 Skill radar charts for visual performance tracking
- 📈 HR analytics dashboard for team-wide insights
- ⚡ Zero dependencies — pure HTML, CSS, JavaScript
- 📱 Fully responsive design

## 🛠️ Tech Stack
| Layer | Technology |
|---|---|
| Frontend | HTML, CSS, JavaScript (Vanilla JS) |
| Charts | Canvas API / Chart.js concepts |
| Deployment | Vercel |

## 🚀 How to Run
Simply open `skillsync-complete.html` in any browser — no setup required!

Or visit the live demo: https://skillsync-orpin.vercel.app/
